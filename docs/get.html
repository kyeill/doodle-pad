Doodle Pad

Drawing and animal stickers for little kids. Android app.

Download the app

Install it

  1. Tap Download the app. Chrome may warn that the file can be harmful. Tap Download anyway.
  2. When it finishes, tap Open (or open doodle-pad.apk from My Files → Downloads).
  3. The first time, Android asks to allow installing apps from Chrome (or My Files). Tap Settings, turn on Allow from this source, then go back.
  4. Tap Install. If Play Protect asks about an unknown app, tap More details → Install anyway.

Updating

Download and install again. It replaces the old version and keeps the drawings.

Samsung Kids

Once installed, add Doodle Pad to Samsung Kids' allowed apps in its parental controls. It doesn't need a browser.

Drawings are saved inside the app on this tablet only. Uninstalling the app deletes them. Drawings made in the web version don't move over to the app.
